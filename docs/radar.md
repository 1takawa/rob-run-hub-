# Радар: карта, которую бот строит по пройденным маршрутам

Карта собирается из записанных заходов (F2) и растёт с каждым новым.

1. **Путь захода.** Из нажатых клавиш и поворотов камеры считается путь по полу (направление берётся из камеры,
   расстояние из времени нажатой клавиши). Единица карты — секунда ходьбы.
2. **Сшивка заходов.** Заходы накладываются друг на друга по местам, где совпали картинки. Расхождение на
   проверенных заходах 0,2–0,7 секунды ходьбы. Результат кэшируется в `profiles/taught/routemap.json`.
3. **Что на карте.** Все пути, двери (по подсказкам «Открыть/Закрыть»), столы (места, где автор нажал E на меню
   «Сбор урожая»), и соседство ключевых кадров: по карте можно идти в обе стороны к любой цели, обходя колонны так,
   как их обходили в записи.
4. **Где бот.** По картинке (а если место не узнано, по мини-карте игры, которая даёт поворот камеры с точностью
   около 1°) бот находит свой ключевой кадр и тем самым своё место и направление на карте.
5. **Память.** Каждый стол, который бот собрал сам, запоминается на карте (`profiles/taught/table_goals.json`).
6. **Радар в оверлее.** Карточка справа вверху: пути, двери (синие квадраты), столы (жёлтые кружки), бот (зелёный
   треугольник), цель (крест).

Код: `routemap.py` (карта), `navigator.py` (ходьба по карте), `radar.py` (мини-карта игры как датчик поворота).

## План плантации (`floorplan.py`)

По нарисованному плану (комната 14×12 м): шесть столов 3×2, три колонны между рядами, лестница вдоль южной стены на
восток. Проходы x=5,2 и x=8,8 ведут мимо двух столов каждый. Из них четыре «точки обхода»:

| точка | где | какие столы по бокам |
|---|---|---|
| A | (5,2; 4,2) | 1 (запад), 2 (восток) |
| B | (5,2; 8,0) | 3 (запад), 4 (восток) |
| C | (8,8; 8,0) | 5 (восток) |
| D | (8,8; 4,2) | 6 (восток) |

Между колонной и столом зазор около 0,6 м: по горизонтальному проходу между рядами бот не ходит, а обходит по
коридору у северной стены или у южной.

Привязка к карте: по лестнице, прямой и известной длины (5,4 м плюс контейнер). Из неё берутся поворот карты к плану
и метры на секунду ходьбы (`stairs_calibration`, на ваших записях 98,5° и 2,58 м/с).

Обход: записанный путь ведёт до конца лестницы (там впервые видно фиолетовый свет), дальше бот знает своё место на
плане (5,2; 0,85), идёт по проходам от точки к точке одним движением, у каждой поворачивается к столам с обеих сторон,
смотрит значок, подходит за меню и решает: пустой / растёт / готов. Собранный стол запоминается вместе с его местом.
