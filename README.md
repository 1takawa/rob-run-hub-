# Hidden pool · ROB RUN edition

Помощник для ROB RUN под Windows: сам доходит из дома до плантации, собирает готовые столы, ведёт таймеры, автокоп и статистику по штатам. Игру он только видит (скриншоты) и нажимает клавиши и мышь; память игры и её файлы не трогает.

## Запуск

Двойной клик по **`start.bat`**. Он сам:

1. находит Python 3.11–3.13 (лучше 3.12, 64-bit); если его нет — предлагает поставить Python 3.12 через winget или открывает страницу загрузки;
2. создаёт окружение `.venv` (если оно сломано — пересоздаёт);
3. ставит библиотеки хаба и оверлея — только в первый раз и когда меняется `requirements.txt`;
4. проверяет, что всё импортируется, и запускает хаб без консоли.

При ошибке окно не закрывается и пишет, что не так; подробности — в `profiles/logs/start.log`. `run.bat` оставлен для старых ярлыков и просто вызывает `start.bat`. Python 3.14 не выбирается: на нём хаб не проверялся.

- Оверлей поверх игры запускается из вкладки **Оверлей**.
- Обновления: кнопка **Проверить обновления** внизу левого меню.

## Вкладки

- **Запуск** — старт, пауза и стоп сбора, таймер до готовности, пакеты за сессию.
- **Плантация** — столы и их таймеры; **Путь до столов**: встань в доме, нажми **F2**, дойди до плантации (у дверей жми E), у каждого стола нажми **F6**, потом снова **F2**. **F3** — пройти путь без сбора, для проверки. Сбор урожая, таймеры и «Видеть столы» — там же.
- **Лаборатория** — в разработке.
- **Автокоп** — выбери класс карточкой; бот жмёт E, как только «Начать службу» светится, сразу подтверждает класс и повторяет, пока не увидит «Завершить службу».
- **Статистика** — штат (ШТАТ EU-…, название, старт сервера), таймер вайпа, заработок с зарплатой копа, время в игре, ноки, смерти, аресты, время в ролях (гражданский / полицейский / грабитель — за сессию и за вайп), приговор за сезон и история штатов.
- **ROB RUN Info** — калькулятор защиты строений и декодеров: строение, предохранители, сколько декодеров каждого качества и время установки.
- **Discord Rich Presence** — фиксированная интеграция с общим переключателем вкл/выкл и переключателями показа данных в разделе «Настройки». При выключении активность очищается и соединение с Discord закрывается. Статус игры и безопасная локация всегда видны, пока интеграция включена; место берётся из Player.log (экран для этого не читается); новое место один раз называется в «Настройках», поселения (роль settler) и неназванные места — «Локация скрыта», роль citizen — Лути-Бей, hubber — Мотель Лени. Роль персонажа тоже из Player.log: citizen — Гражданский, robber — Грабитель, cop — Полицейский.
- **Оверлей** — какие блоки показывать в игре, размер, прозрачность, положение.
- **Настройки** — окно игры (или **Ctrl+F10** в игре), автореконнект, горячие клавиши.

Discord должен быть запущен, а активность ROB RUN разрешена в настройках Discord. Application ID зафиксирован в приложении и не показывается в интерфейсе. В «Настройках» можно отдельно скрыть штат, роль, доход и часы вайпа (соло / пати — в разработке: игра не пишет это в журнал); при скрытом штате остаётся маска `EU-??????` или `NA-??????`. Статус и локация не отключаются.

Загрузи изображения в [Developer Portal](https://discord.com/developers/applications) → приложение ROB RUN → **Rich Presence → Art Assets** — имя ключа Discord подставит сам из имени файла, оно и нужно:

| `discord_location_hidden` | `discord_location_hidden.png` | Чёрная заглушка с белым `?` |

## Клавиши (по умолчанию)

| Клавиша | Действие |
|---|---|
| F8 | старт / пауза / продолжить |
| F9 | аварийный стоп |
| F4 | автосбор вкл / выкл |
| F2 | записать путь до столов |
| F6 | отметить стол во время записи пути |
| F3 | пройти путь до столов (проверка) |
| F7 | прочитать пакеты на экране |
| Ctrl+F10 | привязать окно игры |

## Файлы на этом компьютере (в git не попадают)

- `profiles/default.json` — столы, таймеры, клавиши.
- `profiles/taught/` — записанные заходы (путь до столов) и карта по мини-карте.
- `profiles/seasons.json` — штаты и сезоны статистики; `profiles/stats.json` — пакеты.
- `profiles/autocop.json` — цены классов и итог последнего автокопа.
- `profiles/logs/` — журнал хаба и снимки для разбора ошибок.
- `overlay/stats.json`, `overlay/overlay_settings.json` — счётчики и настройки оверлея.
