# Harvest Assistant

Windows companion for local grow-table timers and a recorded keyboard/mouse route. It uses screen captures, game-window focus checks, and keyboard/mouse input recorded while you walk the route; it does not read game memory or change game files.

## Requirements and launch

- Windows with Python 3.12 available through the `py` launcher.
- A visible game window. The ordinary mode expects it on the primary monitor; optional background mode supports a visible, unminimized window on a secondary monitor.
- Internet access the first time you run the helper so `pip` can install the packages in `requirements.txt`.

Double-click `run.bat`. It creates `.venv`, installs the packages, and launches the hub. The profile and screen templates are saved under `profiles/`.

## Настройка плантации

1. Привяжи игровое окно в **Настройки → Игра** или нажми **Ctrl+F10** в игре.
2. Чтобы пользоваться компьютером во время сбора, включи **Настройки → Игра → Фоновое управление** и оставь игру в оконном режиме на втором мониторе. Не сворачивай и не перекрывай её. В этом режиме хаб отправляет клавиатурные и мышиные сообщения напрямую окну игры; приложение может их игнорировать без фокуса. Сохрани разрешение окна, а если распознавание перестанет совпадать с кадром, перекалибруй маршрут и шаблоны.
3. Добавь столы во вкладке **Плантация** и задай, сколько осталось до готовности каждого. Базовое время роста меняется в **Настройки → Таймеры**, установленные улучшения его сокращают.
4. Проверь клавишу взаимодействия и время ожидания пакетов в **Настройки → Сбор урожая**. Проверь распознавание после ручного сбора через **Прочитать**.

В режиме **Всегда** таймеры идут даже при закрытом хабе. В режиме **Пока игра открыта** хаб отсчитывает время, пока он запущен и видит окно игры.

При записи маршрут запоминает WASD, Shift и движение мыши. Во время обхода хаб нажимает клавишу сбора у каждого отмеченного стола, чей таймер истёк. Таймер сбрасывается после распознавания уведомления о получении пакетов. Если после повторной попытки пакеты не распознаны, хаб завершает обход и ставит автоматизацию на паузу.

### Автокоп

Во вкладке **Автокоп** выбери один из пяти классов карточкой и запусти ожидание у стойки полиции. Кнопкой **Назначить** можно записать отдельную клавишу запуска/остановки (по умолчанию `F10`); после назначения её можно нажимать прямо в игре. Хаб нажимает `E` только когда видит активную кнопку **Начать службу**, подтверждает выбранный класс по светлой кнопке **Подтвердить** и ждёт, пока пройдут сообщения об ограничении по числу копов или задержке. Маршрут до стойки не выполняется: персонажа нужно поставить рядом с NPC.

## Local files

- `profiles/default.json` — table timers, route, hotkeys, and calibration settings.
- `profiles/templates/` — screenshot crops used for visual checks.
- `profiles/logs/harvest_assistant.log` — application startup, automation state, and error log (rotates at 1 MB).
- `.venv/` — Python environment created by `run.bat`.

Keep the profile and its `templates/` folder together when backing it up or moving it.

## Плантация и лаборатория

### Зрительный маршрут · тест

В **Настройки → Маршрут** есть отдельная кнопка **Тестировать путь**. Поставь персонажа в обычную стартовую точку дома, поверни камеру как на первом присланном кадре и нажми кнопку. Тест пытается найти дверь дома, выйти и закрыть её, пройти через крыльцо к контейнеру, открыть и закрыть контейнер, затем найти комнату со столами. Он **не собирает урожай и не меняет таймеры**. Клавиша **F9** или **Остановить тест** прекращает ввод.

Это первый зрительный проход по ориентирам из присланных кадров. После каждого короткого движения хаб снимает новый кадр; если ориентир или ожидаемая подсказка двери не найдены за ограниченное число шагов, он останавливается. Снимок последней ошибки сохраняется в `profiles/logs/visual_route_failure.png`, а текущий этап указан в строке состояния. Повороты и спуск ещё нуждаются в проверке в самой игре; при первом прогоне наблюдай за персонажем и используй F9 при неверном направлении. Разрешение и масштаб игры лучше оставить такими же, как на присланных кадрах.

В верхней части вкладки **Плантация** выбери **Только плантация**, **Только лаборатория** или **Плантация и лаборатория**. Кнопка **Старт** запускает выбранный режим. В совместном режиме основной маршрут начинается, когда готовы все столы и партия лаборатории. В одиночном режиме хаб выполняет действия выбранной зоны по тому же основному маршруту.

### Две записи

1. В разделе **Настройки → Маршрут** нажми **Общий старт**. На полном скриншоте рабочего монитора выдели небольшую неподвижную деталь, которую видно с исходной точки. Сохрани положение персонажа и направление камеры для обеих записей.
2. Нажми **Записать основной**. У каждого стола нажми **F6**, у лаборатории — **Ctrl+F3**. Перед отметкой остановись. Вернись на общий старт с прежним направлением камеры и закончи запись клавишей **F5**.
3. Нажми **Записать ожидание** и запиши короткий круг от общего старта до него же. Закончи через **F5**. Если таймеры истекут во время круга, хаб завершит круг и проверит ориентир перед запуском основного маршрута. Без второй записи хаб дождётся таймеров на месте.

Включи **Авто** для повторения циклов. С выключенным «Авто» хаб останавливается после одного основного маршрута. **F8** запускает, ставит на паузу или продолжает, **F9** останавливает. После паузы в движении вернись на общий старт перед продолжением. Если горячие клавиши переназначены, используй свои клавиши записи, отметки стола, паузы и остановки.

### Настройка лаборатории

Введи длительность партии и оставшееся время в минутах. Остаток `0` означает, что партия уже готова. По одному полному скриншоту для каждого состояния сохрани ориентиры **Готово**, **Партия запущена** и **У станции**, если нужны действия для открытия интерфейса. Скриншоты и координаты должны соответствовать игровому окну на основном мониторе. При переносе окна или смене разрешения их надо настроить заново.

Заполни этапы **Открыть**, **Сбор и запуск**, **Закрыть**. Каждая строка задаёт одно действие:

| Команда | Действие |
|---|---|
| `key e` или `key e 1.5` | Нажать E или удерживать её 1,5 секунды |
| `wait 0.5` | Подождать полсекунды |
| `click 640 480` | Клик левой кнопкой |
| `rightclick 640 480` | Клик правой кнопкой |
| `drag 640 480 750 500` | Перетащить из одной точки в другую |

Хаб проверяет **Готово** перед сбором и запуском. После действий он ждёт признак **Партия запущена**, затем запускает таймер и выполняет этап **Закрыть**. При несовпадении он ставит маршрут на паузу. Таймер можно включить в игровом HUD через **Оверлей → Лаборатория**.
