# Hidden pool overlay

Локальный оверлей для Windows со счётчиками личных ноков, смертей и арестов в ROB RUN.

## Запуск

1. Запусти `start.vbs` из этой папки. Он запускает настройку зависимостей и оверлей без окна CMD.
2. Оверлей сам ищет процесс `ROB RUN.exe` и подключается к нему, когда окно появится.
3. Если автопоиск не сработал, выбери окно игры вручную.

Первый запуск создаст `.venv` и установит зависимости. При следующих запусках launcher сверяет наличие нужных модулей и устанавливает недостающие. Журнал установки находится в `setup.log`.

## Учёт

- Время сессии берётся из времени создания выбранного процесса игры. Поэтому поздний запуск оверлея не обнуляет таймер.
- Текущие разрешение и соотношение сторон читаются из клиентской области окна игры и обновляются при изменении размера. HUD принадлежит окну игры и автоматически скрывается при Alt+Tab или сворачивании игры.
- Пока включена «Личная статистика», оверлей читает новые строки игрового `Player.log` в `%USERPROFILE%\AppData\LocalLow\Kefir\ROB RUN`. Переход в `KnockedOut` даёт нок, в `Dead` — смерть, в `ArrestFinished` — арест.
- При запуске оверлей начинает с конца журнала, чтобы повторно не посчитать уже сохранённые события. Захват экрана и OCR для статистики не используются.
- Статистика сохраняется в `stats.json` рядом с программой. Скриншоты не сохраняются.
- Время сессии отсчитывается с запуска игры. Счётчики включают события, записанные оверлеем. В старых сессиях счётчик арестов начинается с нуля.

Сессия здесь означает один запуск процесса игры. В полноэкранном эксклюзивном режиме Windows может не показывать отдельное окно поверх игры; для такого режима может понадобиться borderless/windowed.

## Управление

- `Ctrl+Alt+F12` — скрыть или показать оверлей.
- `Ctrl+Alt+F11` — закрыть оверлей.
- `Ctrl+Alt+F10` — открыть настройки размера, прозрачности и расположения.
- ПКМ по значку Hidden pool в системном трее — открыть меню, настройки и сочетания клавиш.
- Фарм-таймер вынесен в отдельный блок под карточкой; история сессий открывается из меню трея.

Настройки размера, прозрачности и положения применяются сразу и хранятся в `overlay_settings.json`. Положение X/Y основной карточки и фермы настраивается отдельно в процентах свободной области окна игры. Сочетания можно назначить заново в меню трея; доступны Ctrl/Alt/Shift-комбинации с F1–F12, Insert, Home, End и Pause. Если сочетание занято Windows или другой программой, причина записывается в `overlay.log`.
Запускается только один экземпляр оверлея, чтобы копии не перехватывали друг у друга глобальные клавиши.
Окно настроек временно принимает курсор и фокус; при его закрытии фокус возвращается в игру.

## Блоки

Оверлей состоит из трёх независимых блоков, которые идут одним столбцом и не налезают друг на друга:

- **Личная статистика** — ноки, смерти и аресты за текущую сессию, итоги за всё время и история сессий. Время в игре настраивается отдельно.
- **Плантация** — таймер до ближайшего сбора и три счётчика пакетов: жёлтые, фиолетовые и зелёные (цветная палочка слева, как в уведомлении игры). Вместо времени пишется `СБОР`, когда стол созрел.
- **Лаборатория** — оставшееся время партии или статус «Готово» по данным хаба.

Каждый блок и каждый его элемент включается отдельно в Hidden pool на вкладке «Оверлей». Выключенное не просто скрыто, а перестаёт существовать: блок сжимается, остальное сдвигается. Данные плантации приходят из Hidden pool через `farm_feed.json`, настройки лежат в `overlay_settings.json` и подхватываются на лету.

При запуске оверлей сам закрывает все свои старые копии.

## Распознавание убийств — обязательно доделать позже

Поле «Убийства» показывает прочерк. Автоматический счётчик можно подключить, когда игра начнёт выдавать событие, по которому определяется убийство. Если в Solo такого события не будет, нужен ручной счётчик.

## Зрение автопилота

Пока идёт проход по F3, Hidden pool пишет `vision_feed.json`: оверлей рисует поверх игры карточку «АВТОПИЛОТ» (этап и что делает бот), голубые квадратики узнанных точек, рамку цели (дверь, точка пути) и стрелку к краю экрана, если цель ещё не в кадре. Вне прохода слой скрыт.
